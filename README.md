# Домашнее задание к работе 2
## Условие задачи
После урока 4 ученика решали и отлаживали задачи на компьютере. Первый 
полностью отладил задачу за N минут (число вводится), все последующие тратили 
времени на 10 минут больше предыдущего. Сколько компьютерного времени им 
понадобилось? 
## 1. Алгоритм и блок схема
### Алгоритм
1. Начало
2. Задать константы: количество учеников students_count = 4 и величина прироста времени time_inrease = 10 минут
3. Запросить у пользователя время первого ученика N (в минутах).
4. Вычислить время 1‑го ученика: time1 = N.
Вычислить время 2‑го ученика: time2 = N + time_inrease.
Вычислить время 3‑го ученика: time3 = N + 2 × time_inrease.
Вычислить время 4‑го ученика: time4 = N + 3 × time_inrease.
5. Вычислить общее время: total_time = time1 + time2 + time3 + time4.
6. Вывести условия задачи, время каждого ученика и итоговую сумму затраченного времени.
7. Завершить программу.
